# Online Classroom App

Welcome! This is a Ruby on Rails project built to simulate an online classroom application. This is a practice exercise to learn the process of making a full-stack application with role-based permissions and database management.



## Features
- **Secure Authentication:** Users can sign up and log in using Devise.
- **Teacher/Student Roles:** Built using Rails Enums to differentiate user permissions.
- **Course CRUD:** A full "Create, Read, Update, Delete" system for course management.
- **PostgreSQL Database:** A database structure for storing user and course data.

## Getting Started and Key Details

### Prerequisites
* **Ruby:** 3.4.9
* **Rails:** 8.1.3
* **PostgreSQL**

### Setup
1. **Clone the repo:**
   `git clone <your-github-link-here>`
2. **Install dependencies:**
   `bundle install`
3. **Setup the database:**
   `rails db:prepare`
4. **Start the server:**
   `rails server`

Go to `http://localhost:3000` to see the app. 
Currently, go to `http://localhost:3000/courses` to see what is currently implemented.
